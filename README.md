# 🧪 Heviane Labs

Bem-vindo ao **Heviane Labs**! Este é o meu espaço dedicado a experimentos práticos, pesquisas de arquitetura de software, *spikes* de engenharia e projetos de cursos e certificações.

A proposta desta organização é isolar meus laboratórios de estudo do meu perfil principal, mantendo um histórico organizado de evolução contínua.

---

## 🎯 Foco dos Laboratórios

- **🔬 Spikes & Provas de Conceito (PoC):** Testes de novas bibliotecas, frameworks e padrões de arquitetura (Clean Architecture, DDD, Event-Driven).
- **📚 Projetos de Cursos e Bootcamps:** Implementações práticas desenvolvidas durante treinamentos e especializações técnicas.
- **⚡ Snippets & Desafios:** Algoritmos, resoluções de desafios de código e pequenos scripts utilitários.
- **🏗️ Infraestrutura & DevOps:** Testes com Docker, pipelines de CI/CD (GitHub Actions) e configurações de ambiente.

---

## 🛠️ Stacks & Tecnologias Exploradas

- **Backend:** .NET (C#), ASP.NET Core, Entity Framework Core, PostgreSQL, SQL Server.
- **Frontend & Mobile:** Blazor, .NET MAUI, Web API RESTful.
- **DevOps & Tooling:** Docker, GitHub CLI (`gh`), Git, Linux.
